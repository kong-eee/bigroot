# 온통청년 API (지역 청년정책 피드)

`/policy-feed` 탭 ①에서 **주거** 분야(`lclsfNm=주거`) 청년정책을 지역별로 조회합니다.

서버는 온통청년 JSON API `https://www.youthcenter.go.kr/go/ythip/getPlcy` 를 사용합니다.  
(구 엔드포인트 `/opi/youthPlcyList.do` + `openApiVlak` 는 일부 환경에서 `:8080`으로 리다이렉트되어 실패할 수 있습니다.)

## 키 발급

1. [온통청년](https://www.youthcenter.go.kr) 회원가입
2. 마이페이지 → **오픈(OPEN) API** → 인증키 신청·승인
3. `.env.local`에 추가:

```env
YOUTH_CENTER_API_KEY=발급키여기에
```

키가 없으면 예시 데이터 2건이 표시됩니다.

## API (서버 프록시)

`GET /api/youth-policies?sido=11&scope=all&page=1&pageSize=20`

| 파라미터 | 설명 |
|----------|------|
| `sido` | 행정 시·도 코드 (`11` 서울, `41` 경기, …) |
| `scope` | `local` \| `national` \| `all` |
| `page` | 페이지 (1부터) |
| `pageSize` | 건수 (최대 50) |

## 인증 파라미터

- `.env.local`의 `YOUTH_CENTER_API_KEY` 값을 요청 시 **`apiKeyNm`** 으로 전달합니다.
