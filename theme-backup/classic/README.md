# 이전 UI (classic) — 운영 UI

**현재 사이트는 classic UI만 사용합니다.**

| 운영 파일 | 설명 |
|-----------|------|
| `app/components/NavbarClassic.tsx` | 상단 네비 |
| `app/components/HomeClassic.tsx` | 홈 |
| `app/components/ClassicBrandLogo.tsx` | 로고 |
| `app/globals.css` `[data-theme='classic']` | 파란 톤 디자인 토큰 |

## 새 UI (refresh) 보관

개편안은 `theme-backup/refresh/` 와 `globals.css`의 `[data-theme='refresh']` 블록에 보관되어 있습니다.

## 이 폴더 (theme-backup/classic)

UI 개편 **직전** 스냅샷입니다. 운영 코드와 다를 수 있으니 참고용으로만 사용하세요.
